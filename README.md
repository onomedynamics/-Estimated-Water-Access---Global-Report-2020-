# Project name -- 🌍 Estimated Water Access - Global Report (2020)

This repository provides a curated dataset on global water access levels as of 2020. The data highlights disparities in access to safe drinking water across countries and regions, supporting global efforts to improve clean water accessibility in line with **Sustainable Development Goal 6 (SDG 6): Clean Water and Sanitation**.

---

## 📁 Dataset Overview

- File -- estimated water access - Global_2020_report.csv
- Format: CSV
- Year Covered: 2020
- Scope: Global (country-level)
- Data Source:  WHO/UNICEF JMP

### 🔑 Key Variables

| Column               | Description                                                           |
|----------------------|------------------------------------------------------------------------|
| `Country`            | Country name                                                           |
| `Region`             | World region or continent                                              |
| `Population`         | Estimated population                                                   |
| `Safely managed (%)` | % with access to safely managed drinking water services                |
| `Basic (%)`          | % with access to basic drinking water                                  |
| `Limited (%)`        | % with limited access                                                  |
| `Unimproved (%)`     | % using unimproved water sources                                       |
| `Surface water (%)`  | % relying on surface water (e.g., rivers, lakes, unprotected sources)  |
